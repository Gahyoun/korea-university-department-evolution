# How Large Should Academic Departments Be? — Korea

한국 대학 학과 Alluvial 계보와 연도별 전임교원 규모를 결합한 temporal analysis 결과 묶음이다.

- [`REPORT.md`](REPORT.md): 지도교수 보고용 결과·해석·한계
- [`how_large_academic_departments_KR.ipynb`](how_large_academic_departments_KR.ipynb): 실행 완료 분석 노트북
- [`figures/`](figures): 보고용 그림
- [`tables/`](tables): 집계 결과표

원자료 Excel은 개인정보나 비공개 로컬 경로와 함께 저장소에 포함하지 않는다. 재실행 코드는
상위 [`analysis/`](../analysis) 폴더에 있으며, 교원 자료 위치는 `FACULTY_DATA_DIR`로 지정한다.

# 방법론 · 처리 기준 (METHODOLOGY)

이 문서는 원자료 → 산출 데이터까지의 **모든 결정론적 처리 규칙**을 명세한다.
목표는 재현성이다. 원본 `<연도>.xlsx`(2014–2026)와 이 저장소의 `build/` 스크립트만 있으면
동일한 산출물이 나온다(`make all`).

> 인식론적 지위: `학과상태(신설/통합/분리/폐지)`는 원자료의 **관측값**이다.
> 연도 간 **연결(연속·통합·분리)** 과 **소계열 귀속**은 학과코드·명칭·소계열에 기반한 **추정값**이다.
> 아래 규칙은 그 추정의 명시적 정의다.

## 1. 대상 · 필터링 (`normalize.py`)

**연도 범위**: 2014–2026 (대학알리미 학교별 학부(과) 리스트, 각 연도 파일).
헤더 위치·컬럼명이 연도별로 달라 별칭(alias) 매핑으로 흡수한다.

**학교 유형(학교구분/학제)**: `대학교 · 산업대학 · 교육대학`만 포함.
사이버대학·방송통신대학·각종학교·기술대학·기타대학 제외.
2026은 유형이 `학교구분`이 아니라 **`학제`** 컬럼에 있으므로 그쪽을 우선 사용한다.

**활성 학과**: `학과상태`에 `폐지/폐과`가 포함되면 그 해에 비활성으로 본다.
`신설·기존·변경·통합·분리`는 활성. (활성=신입생을 유효하게 받는 학과.)

**제외(모집단위·비정규 편성)** — `is_excluded()`:
| 범주 | 규칙 |
|---|---|
| 무전공 | `자유전공·자율전공·무전공·광역·계열모집`, `대계열=광역계열` |
| 모집단위 | `모집단위·통합모집·새내기·단일계열·단일학부`, 이름이 `~계열`로 끝, 단과대학명 그대로(`~대학` + 학과/학부/전공 없음) |
| 교양 | `교양·학부대학·기초교육·기초교양·기초과학부·기초의과학·글로벌리더` (학과명 또는 단과대학) |
| 1학년전용 | `1학년·일학년·신입생·예과군·학부(1` |

## 2. 정규화

- **가운뎃점 통일**: `ㆍ(U+318D)·・(U+30FB)·‧·⋅·∙·･·•` 및 주변 공백 → `·`.
  계열명·학과명 모두 적용(2014–18 `ㆍ` vs 2019+ `・` 로 같은 계열/학과가 갈리던 문제 교정).
- **대계열 정규화**: 표기 변동(`인문ㆍ사회` / `인문사회계열` …) → `인문사회·공학·자연과학·예체능·의학` 5분류.
- **2026 중/소계열 부재**: 2026 파일은 대계열만 수록 → 직전 연도(≤2025)의 동일 `(학교,학과명)`에서 **중/소계열을 상속**. 매칭 없으면 소계열 미상(대계열 폴백).
- **명칭 매칭 정규화(`norm_name`)**: 괄호·공백 제거 후 접미 `학과/학부/전공/과/부`를 일관 정리해
  `간호학과 = 간호학전공 = 간호학부 = 간호학`(핵심어+`학`)로 통일.

## 3. 학부 단위 집계 (`lineage.py`)

`OO학부 XX전공` / `OO학부(XX전공)` 형태는 **학부(OO학부)를 한 노드**로 집계한다.
- `members` = 소속 전공 목록, `msz` = 전공/학과 수 = **노드 크기**.
- `cores` = 전공에서 학부 접두를 제거·정규화한 집합(학부 개명 판정용).
그 외 `OO학과/OO과`는 자기 자신이 노드(msz=1).

## 4. 학교 식별 · 명칭변경 · 통합

- **학교코드(2021+)** 는 명칭변경에도 안정적 → 코드로 캐노니컬 학교명(가장 최근명) 부여.
  국립화(`OO대→국립OO대`, `안동대→국립경국대`)·분교 개명(`연세대(원주)→연세대(미래)`)은
  **동일 학교**로 취급(이벤트 없음). 코드 없는 2014–2020은 명칭 매칭.
- **학교 간 통합만 별도 표기**(흡수 학교 = 하단 밴드):
  - `경상국립대 = 경상대 + 경남과학기술대` (2022)
  - `강원대 + 국립강릉원주대` (2026)
  - `상명대(천안)→상명대`, `홍익대(세종)→홍익대` (분교의 본교 흡수, 2017)
- **빈 학교 제외**: 활성 학과가 전 연도 0인 유령(산업대 중복 등) 제외.
- **학교 목록 정렬**: 가나다순.

## 5. 계보 링크 추론 (연도 Y → Y+1, `link_pair`)

우선순위대로 1:1/다:1/1:다 매칭(먼저 매칭되면 확정):

1. **dcode**(학교별학과코드, 2022+) 동일 → 연속(cont)
2. **정규화 명칭** 동일 → cont
3. **`X` vs `X학`** (학 유무만 차이) → cont. 핵심어 1글자(수학·화학·의학·약학·법학)는 보호
4. **세부전공 과반 일치**(`setjac(cores) ≥ 0.5`) → cont *(나노·신소재공학부 → 신소재공학부)*
5. **상태 통합/분리** + 같은 소계열 → merge / split
6. **학부 포함**: 학부명이 상대 학과명(또는 어간)을 포함 → merge(A로) / split(A에서). 학부명에 여러 학과 어간이 들어가면 **모두 split** *(기계항공및원자력공학부 → 기계공학과+원자력공학과)*
7. **소프트(재편/개명)**: 같은 소계열 + 명칭 bigram Jaccard ≥ 0.4 → soft

**Gap-bridge**: 신설(좌측 무링크) 노드가 이전 연도(≤4년)에 같은 `(정규화명, 소계열)`로 존재했으면 연결(재등장, 가운뎃점 변형 등으로 끊긴 경우 복원).

**폐지 재판단(dead-rescue)**: 후속 없는(사망) 노드를 이후(≤5년) 노드와 연결해 폐지 오분류를 교정:
- (1) 어간(stem) 일치 — `과학/공학/학/과/부` 접미 제거 + 동의어(`수리→수학`). *원예학과→원예과학과, 수학과→수리정보과학과*
- (2) 세부전공 과반 일치(gap)
- (3) **같은 소계열** + 어간 접두 포함(단순 단어 첨삭). *축산생명학과→축산학과* — 반드시 같은 소계열이라, 소계열이 다른 `경영학(경영학)` vs `경영정보학(경영정보학)`은 연결 안 됨
- (4) **소계열 유일**: 같은 소계열 후속 후보가 정확히 1개면 연결. *수학과→수리데이터사이언스학과*

## 6. 학교 통합 처리 (밴드)

흡수된 학교는 하단 밴드(band≥1)로 자체 타임라인을 그리고, 통합 연도에 본교로 합류시킨다.

- **cross-band(합류) 링크**: 흡수 학교 마지막해 학과 → 본교 통합연도 학과.
  명칭 동일 / 학부 포함으로 우선 매칭.
- **통합 legacy 중복 제거(ghost)**: 본교(band0) 학과가 흡수밴드와 **동명**이고 등장이 `[통합−1, 통합]`에만 있으며 통합연도까지만 존재(미존속) → 통합 직후 폐과된 **순수 중복기재**로 보고 제거(흡수밴드로만 표시). **통합 후 존속**하는 흡수 학과는 계승으로 **유지**한다.
- **같은-소계열 흡수(colocated)**: `경상국립대`처럼 **같은 도시 통합**은, 본교 통합연도 신설 학과의 소계열이 흡수밴드에 있으면 이름이 달라도 흡수밴드 같은 소계열 학과에서 **통합 유입**으로 연결(*동물생명융합학부·축산과학부·건설시스템공학과·회계세무학부* 등). **캠퍼스 분리 통합**(`강원대`←국립강릉원주대)은 보수적: 소계열이 같아도 **명칭 유사도 ≥0.3**일 때만 통합(분리운영 보존).

## 7. 노드 크기 · 이벤트

- 노드 크기 = 학부/학과에 묶인 **전공·학과 수(msz)**. 리본(흐름) 두께 = 연결 규모.
- 이벤트(`finalize_events`): 유입 링크 없음+비최초 = 신설, 유출 없음+비최종 = 폐지,
  유입 다중/merge = 통합, 유출 다중/split = 분리, 대계열 이동 = cross.

---

## 8. 소계열 명칭 분화 (`build_namesplit.py`)

전국 대학 계보 링크를 **명칭 단위로 집계**: 노드=(연도,학과명), 크기=학교 수, 링크=명칭 전이(전이 학교 수).
- 소계열 노이즈(`N.C.E.`, 대계열 fallback) 제외.
- 표시 명칭 정규화: `물리학과=물리학부=물리학전공`, 같은 소계열에 `X`/`X학` 공존 시 `X학`으로 통일.
- 대계열 ▸ 중계열 ▸ 소계열 계층 인덱스 + 소계열별 연도별 학과 수(증감).

## 9. 키워드 Temporal (`build_keywords.py`)

`kiwipiepy` 명사(NNG/NNP/SL) 추출 + 접미(공학과/학과/전공/과) 정리 + 불용어 제거.
`신설/활성` × `대계열(전체+5)` 별 키워드 연도 빈도, 초기3년 대비 최근3년 빈도차로 급상승 랭킹.
